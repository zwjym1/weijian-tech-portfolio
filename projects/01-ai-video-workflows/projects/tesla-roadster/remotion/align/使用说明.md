# 素材对齐工具：使用说明（新手版）

用这个工具可以在网页上拖动、调整每个实拍镜头：
- 镜头从视频的第几秒开始（入点），到第几秒结束（出点）
- 镜头放在配音的哪个字上

点「保存」之后，渲染视频时会直接用你调好的数值，不用改任何代码。

## 一、第一次准备（只做一次）
1. 安装 Node.js：打开 https://nodejs.org ，下载 **LTS** 版，一路点「下一步」装完。
2. 把整个项目文件夹 `tesla-roadster\remotion` 复制到电脑上，例如放到
   `C:\Users\Administrator\tesla-roadster\remotion`。
   - **要带上**：`public` 文件夹（素材视频和配音都在里面）。
   - **不要带**：`node_modules`。

## 二、启动工具
- 方法 A：双击 `remotion\align\start-align.bat`。第一次会自动安装依赖，大约需要几分钟，之后再启动就很快了。
- 方法 B：在 `remotion` 文件夹空白处按住 Shift 点右键，选「在终端中打开」，然后输入：
  `npm install`（只有第一次需要），再输入 `npm run align`。

启动后浏览器会自动打开 http://localhost:3210 。黑色命令窗口在使用期间不要关，关了工具就停了。

## 三、界面
- **左上**：成片实时预览（带配音）。下面的进度条可以拖动，空格键播放或暂停。
- **右上**：当前选中镜头的「原素材」预览，以及入点、出点、速度的设置。
- **下方时间线**，从上到下依次是：
  - 时间刻度
  - 句子
  - 逐字（播到哪个字，哪个字会变黄）
  - 配音波形
  - 图形段（灰色斜纹，比如 3D 拆解。这些不是实拍，不能拖）
  - 每个实拍镜头各占一行彩色条

## 四、常用操作
| 想做什么 | 怎么做 |
|---|---|
| 跳到某个字 | 点时间线上的字或句子 |
| 选中一个镜头 | 点它的彩色条，或点左边的名字 |
| 整个镜头往前或往后挪 | 按住彩色条左右拖 |
| 镜头开始早一点或晚一点（画面跟着裁） | 拖彩色条的**左边缘** |
| 镜头结束早一点或晚一点 | 拖彩色条的**右边缘** |
| 位置不变，只换用素材里的另一段 | **Shift + 拖**彩色条 |
| 精确找画面 | 在右边拖素材进度条，或点「◀ 1帧 / 1帧 ▶」 |
| 让这一帧在镜头开头出现 | 按「设为入点」（键盘 I） |
| 让镜头在这一帧结束 | 按「设为出点」（键盘 O） |
| 让这一帧正好出现在某个字上 | 先把播放头放到那个字上，再在右边找到想要的画面，按「这一帧对准播放头」（键盘 A） |
| 慢放或快放 | 改「速度」，例如 0.5 就是半速 |
| 撤销 | Ctrl+Z |
| 保存 | Ctrl+S，或点「💾 保存」 |

**小提示：**
- 「吸附」打开时，拖动会自动对齐到字的开头和结尾。
- 彩色条有**红框**，表示和别的镜头重叠了。
- 右边出现「⚠ 出点超出素材长度」，说明素材不够长，结尾会停帧或黑屏。
- 每次保存，旧的版本会自动备份到 `align\backups\`，误操作可以从这里找回。

## 五、保存之后
- 时间线保存在 `src\v3\footage-timeline.json`。
- 也可以点「导出 JSON」，把文件发给别人。别人用「导入 JSON」打开即可。
- 重新渲染预览：`npx remotion render src/index.tsx RoadsterShortV3 out/v3-raw.mp4 --scale=0.5 --gl=angle`
  （正式成片要等确认后再渲染）

## 六、以后做别的视频
1. 复制 `align\projects\roadster-v3.tsx`，改成新视频的合成组件、字幕时间和默认镜头。
2. 在 `align\project.config.json` 里改两项：
   - `entry`：指向新复制的项目文件
   - `timeline`：新视频的时间线文件

## 七、混音（v3.2 新增）
时间线上方有一条「混音」栏：
- **配音 / 音效 / BGM**：三个音量滑杆，单位是 dB。0dB 是当前默认值，+3dB 大约响一倍感，-6dB 大约小一半。
- **说话时压低BGM**：人声出现时，BGM 自动压低多少 dB（默认 10）。数值越大，人声越清楚，BGM 越像「让路」。
- **BGM 音量包络**（时间线里的一行）：
  - 点空白处：加一个点，越往上越响。
  - 拖点：调整时间和音量。
  - 双击点：删除。
  - 绿色曲线：最终 BGM 音量，已经包含说话时的压低。

所有改动都会实时在左上角预览里听到。点「保存」后，这些数值存进 `src\\v3\\footage-timeline.json` 的 `"audio"` 部分，渲染时直接使用。

## 八、只改了声音？几秒钟更新成片
如果只调整了混音（音量、压低、BGM 包络），**不用重新渲染画面**。
1. 在工具里点「保存」。
2. 在 `remotion` 文件夹打开终端，输入：`npm run remix-audio`
3. 它会做三件事：
   - 按时间线 JSON 只渲染音频
   - 把响度统一到 -16 LUFS
   - 直接替换成片 `特斯拉Roadster-v3.mp4` 里的声音（画面原样复制，不重新编码）

   混好的音频会另存为 `out\master-audio.wav`。

如果改了画面（镜头入点、出点等），就需要完整渲染：`npm run render:master`。
