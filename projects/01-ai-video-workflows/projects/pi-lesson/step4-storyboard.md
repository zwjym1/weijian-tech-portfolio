# 圆周率的发展历程 · STEP 4 分镜与视觉方案
依据：`step3-script-final.md`（由 v3 修改）（第4章已删去分数和计算器段；画面中**不出现 355/113、22/7**）。
总时长估算 ≈ **298秒（约5分钟）**，按4.2字/秒计，含停顿；实际以配音时长为准，下表时间为预估。
路线：小学**学习课**风格，和梯度下降科普短视频分开，**不使用**黑金粒子钩子风格。

## 1. 画幅建议：16:9（1920×1080，30fps）
- **理由**：①课堂投屏、电视、B站、平板横屏观看，都是16:9；②核心画面“多边形+数据表”需要左右并排（左边图形，右边表格），竖屏放不下；③字幕和数字可以放得更大，后排学生也看得清。
- **竖屏需求**：如果以后要剪抖音片段，可单独切第3章，做成9:16“上图下表”的竖版，不作为主版本。

## 2. 整体视觉风格
- **基调**：明亮、干净的“方格作业本”风格，像同学在本子上边画边讲。扁平矢量图形，圆角，粗描边（6–14px）。
- **调色板**
| 用途 | 颜色 | Hex |
|---|---|---|
| 背景（米白纸） | 暖米白 | `#FFF8EC` |
| 方格线 | 浅卡其 | `#EDE4D3` |
| 主文字/描边 | 墨蓝黑 | `#2B2D42` |
| 主色/章节标签 | 亮蓝 | `#3A86FF` |
| 强调/提问 | 橙 | `#FF8C42` |
| 高亮/π值 | 柠檬黄 | `#FFD23F` |
| 正确/第二色 | 青绿 | `#2EC4B6` |
| 重点数字/关键结论 | 粉红 | `#FF5D8F` |
| 古代章节（纸/木） | 古纸 `#F4E3C3`，木桌 `#C98B4F`，算筹 `#F2D8A7` | |
| 计算机章节背景 | 深夜蓝 | `#1B2A4A` |
- **字体**：Noto Sans CJK SC Bold（字幕、标题、数字），Regular（注释）；古文引用“割之弥细，所失弥少”用 Noto Serif CJK SC Bold。数字等宽对齐，用 Noto Sans Mono CJK SC，或 tabular-nums。
- **字幕**：底部居中（y≈920，1080p 下），64px 白字，8px 墨蓝描边，一次显示一个短句，不带标点（沿用 v4 字幕规则）。
- **章节标签**：左上角蓝色胶囊，例如“第3章 割圆术”。
- **吉祥物（可选）**：一个圆形小角色“圆圆”，眼睛是两个小点，头顶有“π”呆毛。只在“想一想”时出现在右下角举牌，平时不出现，避免分心。
- **“想一想”卡**：橙色圆角卡片，写着“想一想”和问题，2秒倒计时小圆环，卡片轻微弹跳。
- **动效原则**：弹性缓动（spring，damping≈14），每个数字出现时有轻微放大回弹；不闪烁、不剧烈抖动；任何时候屏幕上最多3个新元素。
- **音效**：轻柔的“叮/啪/纸张”音效；不用重低音冲击。

## 3. 分章分镜
> **比例规则**：所有表示长度的画面都必须按真实比例绘制（车轮轨迹=π×直径，直径木棍=车轮直径，多出段=0.1416×直径，六边形边=半径，多边形顶点在圆上，差距条形图按实际数值缩放）。制作时用代码按数值计算，不靠手摆。
时间为预估（按 v3 字数）。“台词触发”指动画和配音中的哪个短句对齐，实际以词级时间戳为准。
